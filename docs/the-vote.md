# The Vote portfolio showcase

Added on 7 November 2026, linking to the existing published game at https://trinitrointeractive.itch.io/the-vote. The itch.io page was read to confirm its current version, supported controls, and implemented features; no game upload or page changes were needed.

The showcase describes the v0.1.0 political strategy card game: voter investigation and negotiation, policies and promises, three practice elections, a branching career, regional canvassing, browser saves, and reduced-motion settings. Career stages 1–11 are playable; unauthored national stages 12–15 remain future content. Content is configured in `src/data/content.ts`.

The project card uses an optimized WebP export of `G:/The Vote/Docs/Development/Screenshots/WebGLDesktop.jpg`. The detail dialog uses `GovernorCampaign.png` from the same directory. These are genuine game captures. Both stay colorful against the portfolio's dark frame. The existing local Unity source checkout and its unrelated ProjectSettings modification were left untouched. The source repository remains private, so the portfolio does not expose a broken public source link.

The game runs on itch.io. Opening the portfolio or its detail dialog fetches only small local images, never the WebGL game runtime. PLAY PROJECT opens the existing game in a new tab with `noopener noreferrer`.
